# ПЛАН

Локальная интеллект-карта и дорожная карта проектов. Приложение работает
полностью офлайн, данные хранятся в папке `data/` рядом с программой.

- **Платформа:** Windows 10/11 x64 (сборка), исходники кроссплатформенные
- **Движок:** Electron 44.7.2
- **Версия:** 1.6.0
- **Режим:** портативный (данные пишутся рядом с `.exe`)

## Что внутри

| Каталог | Назначение |
|---|---|
| `electron/` | главный процесс, preload, файловое хранилище, модель данных |
| `dist/` | собранный интерфейс (HTML/CSS/JS), тема и надстройка «PRO» |
| `build/` | иконка приложения (`icon.png`, `plan.ico`) |
| `package.json` | имя, версия, точка входа |

## Данные

Приложение хранит рабочие данные рядом с `.exe`:

```
<папка приложения>/
├── ПЛАН.exe
├── resources/app/   ← код
└── data/
    ├── plan.json    ← текущий план
    ├── backups/     ← до 10 резервных копий
    └── system/      ← кеш, сессии, логи
```

`data/` **не входит в репозиторий и не публикуется**: там рабочие планы
и служебные данные. При первом запуске приложение создаёт папку заново.

## Установка (Windows)

1. Скачайте `ПЛАН-Setup-1.6.0.exe` из раздела **Releases**.
2. Запустите установщик. Установка идёт в профиль пользователя
   (`%LOCALAPPDATA%\Programs\ПЛАН`), права администратора не нужны.
3. Ярлыки появятся на рабочем столе и в меню «Пуск».

Альтернатива — портативная сборка `ПЛАН-portable-1.6.0-win-x64.zip`:
распакуйте в любую папку с правом записи и запустите `ПЛАН.exe`.
